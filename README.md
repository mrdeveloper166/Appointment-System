# 📅 Appointment System

A PHP and MySQL-based Appointment Management System designed to make appointment booking and management simple and efficient.

## 🚀 Features

* User appointment booking
* Appointment management
* Admin dashboard
* View and manage appointments
* Customer information management
* MySQL database integration
* Responsive user interface
* Secure PHP-based backend

## 🛠️ Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/mrdeveloper166/Appointment-System.git
```

2. Move the project folder to the XAMPP `htdocs` directory.

3. Start **Apache** and **MySQL** from XAMPP.

4. Create a MySQL database.

5. Import the provided `.sql` database file into phpMyAdmin.

6. Update the database connection settings in the project.

7. Open the project in your browser:

```text
http://localhost/Appointment-System/
```

## 📂 Project Purpose

This project demonstrates a complete appointment booking workflow using PHP and MySQL, including frontend booking functionality and backend appointment management.
